## Quick Start — 10 Minutes to First Lead

### Step 1: Set Up Your Command Center

1. **Clone this repository** to your local machine or GitHub Codespace
2. **In Claude.ai**, create a new Project named `"Command Center — Pipeline 369"`
3. **Upload all 6 core files** (`01_LENS.md` through `06_LEADS.csv`) to the Project Knowledge
4. **Start every conversation** with:
   > *"You have full access to the Project Knowledge. Operate using the fused lens. Reference the pipeline, scripts, templates, and prompt chains as needed."*

### Step 2: Run the Scraper

1. Go to **Apify** (free account)
2. Use the `google-maps-scraper` actor with the configuration from `02_PIPELINE.md`
3. Export the results to CSV
4. Filter for: `reviews_count < 10`, `website != null`, `avg_rating >= 3.5`
5. Enrich the top 10 leads with names and emails (Hunter.io, Clearbit, or manual call)

### Step 3: Generate Your First Audit

1. Copy `05_PROMPT_CHAIN.md` — P1
2. Paste it into your AI with the lead's URL
3. Run P2, P3, and P4 sequentially
4. Apply the 5‑point Human Filter from `05_PROMPT_CHAIN.md`
5. Generate the PDF using the Canva template from `03_SCRIPTS.md`

### Step 4: Execute Outreach

1. Use the scripts from `03_SCRIPTS.md`:
   - Cold Call (30‑45 seconds)
   - Voicemail (60 seconds)
   - Direct Voice Memo (60 seconds)
2. Send the PDF immediately after the call/memo
3. Wait 3 days, then send the Follow‑Up script
4. If they reply "YES" or "MORE", use the Retainer Pitch script

### Step 5: Close, Collect, Repeat

1. Send the proposal
2. Collect 50% upfront (Wave or PayPal)
3. Deliver the work
4. Collect the remaining 50%
5. Move to the next lead

**Expected Result:** 1‑2 signed retainers from your first batch of 10 leads. $500–$3,000/mo recurring revenue from ~8 hours of active work.

## Token Optimization — Operating in Claude

This repository is designed to minimize token consumption in Claude sessions:

| Rule | Why |
| :--- | :--- |
| Set effort at session start | Changing `/effort` mid‑session invalidates the entire prompt cache |
| Start fresh sessions daily | Resuming giant conversations burns tokens unnecessarily |
| Keep `CLAUDE.md` under 500 lines | Global rules are loaded on every prompt—keep them lean |
| Use skills for workflow‑specific instructions | Skills load only when needed—costs ~30‑100 tokens at startup |
